# 运行测试样例

这些文件用于在 DSH-MYAGENT 中手动测试“运行”按钮。

| 文件 | 语言 | 预期输出 |
|---|---|---|
| hello.py | Python | Hello from Python! + 3 行 line |
| hello.R | R | Hello from R! + 3 行 line |
| hello.js | Node.js | Hello from Node.js! + 3 行 line |
| hello.sh | Shell | Hello from Shell! + 3 行 line |

打开任意文件后，点击右上角 **▶ 运行**，底部会显示运行输出。
